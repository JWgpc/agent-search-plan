# 决策记录模板

复制本模板到 `docs/agent_search/reports/decisions/` 或追加到 `03_risks_and_open_questions.md` 决策表。

---

## DEC-YYYYMMDD-001

| 字段 | 内容 |
|------|------|
| **日期** | YYYY-MM-DD |
| **决策 ID** | D1 / D2 / … |
| **标题** | （一句话） |
| **背景** | 为什么需要决策 |
| **选项** | A: … / B: … / C: … |
| **决定** | 选定方案 |
| **理由** | |
| **决策人** | |
| **影响范围** | 阶段 x,y；文件/预算 |
| **复审日期** | 可选 |
