# 阶段门禁检查清单

每个阶段结束前，负责人与 Agent 共同核对。**全部必选项完成后**方可进入下一阶段。

---

## 阶段 1 Gate

- [ ] `search_landscape_report.md` 已提交  
- [ ] shortlist 3–5 条，含集成难度  
- [ ] D1 已决策或明确延期原因  
- [ ] 人工评审会议已举行  

## 阶段 2 Gate

- [ ] `search_eval/` 结构已定（代码可占位）  
- [ ] task_lists 已 curated（非仅启发式扫描）  
- [ ] D3、D4 已写入 decision_log  
- [ ] baseline 至少 1 模型、1 次完整 run  
- [ ] baseline 报告已审核（排除 infra 误判）  

## 阶段 3 Gate

- [ ] 四条冒烟实验均有结果或 documented skip 理由  
- [ ] `method_decision_memo.md` 已发布  
- [ ] D2、D8 已决策  
- [ ] 全量训练预算已批准  

## 阶段 4 Gate

- [ ] SFT/RL 数据 manifest 完整  
- [ ] 自动质检报告达标  
- [ ] ≥5% 人工抽检记录  
- [ ] SFT/RL 配比已确认  

## 阶段 5 Gate

- [ ] ≥2 候选 checkpoint  
- [ ] 训练日志与 eval 曲线归档  
- [ ] D7（混训策略）已记录  

## 阶段 6 Gate

- [ ] 全量 benchmark 完成  
- [ ] evaluation_report 已发布  
- [ ] top-20 失败 case 人工分析  
- [ ] production / merge 书面 sign-off
